# Security Policy / سیاست امنیتی

## فارسی

### گزارش آسیب‌پذیری امنیتی

اگر آسیب‌پذیری امنیتی در این پروژه پیدا کردید، لطفاً آن را به‌صورت عمومی
(مثلاً در ایشوهای گیت‌هاب) گزارش ندهید. در عوض، جزئیات را به آدرس زیر ایمیل
کنید:

**security@parsigames.org**

*(این یک آدرس موقت است؛ صندوق ورودی واقعی در فاز بعدی پروژه راه‌اندازی
می‌شود.)*

لطفاً در گزارش خود، توضیح مشکل، مراحل بازتولید آن، و میزان تأثیر احتمالی را
ذکر کنید. تلاش می‌کنیم در سریع‌ترین زمان ممکن پاسخ دهیم.

### حریم خصوصی و ناشناس‌ماندن اعضا

حفظ ناشناسی و حریم خصوصی اعضا یکی از ارزش‌های بنیادین این پروژه است. راهنمای
کامل امنیت عملیاتی (OPSEC) برای اعضا در فاز بعدی پروژه تدوین و منتشر خواهد
شد.

## English

### Reporting a Security Vulnerability

If you discover a security vulnerability in this project, please do not
report it publicly (e.g., in GitHub issues). Instead, email the details to:

**security@parsigames.org**

*(This is a placeholder address; the real inbox will be set up in a later
project phase.)*

Please include a description of the issue, steps to reproduce it, and its
potential impact in your report. We will make every effort to respond as
quickly as possible.

### Member Privacy and Anonymity

Member anonymity and privacy are a core value of this project. A full
operational security (OPSEC) guide for members is planned and will be
published in a later phase.
