# Parsi Games / پارسی گیمز

## فارسی

### دربارهٔ پروژه

پارسی گیمز پلتفرمی دوزبانه (فارسی و انگلیسی) است که توسعه‌دهندگان بازی، هنرمندان
دیجیتال، و مشارکت‌کنندگان متن‌باز ایرانی را در سراسر جهان به هم متصل می‌کند. این
پروژه برای آینده‌ای ساخته می‌شود که ایران دوباره و آزادانه به جامعهٔ بین‌المللی
بپیوندد. تا آن زمان، هدف این پلتفرم گردآوری، مستندسازی، و تولید محتوا و کد
متن‌باز از سوی متخصصان ایرانی است — چه آن‌هایی که در سراسر دنیا پراکنده‌اند و چه
جامعهٔ بزرگ و توانمند متخصصان داخل ایران — تا مجموعه‌ای آماده از افراد، آثار
هنری، و کد از پیش شکل گرفته باشد.

### سه رکن پروژه

1. **فنی و مهندسی** — معرفی افراد، پروژه‌ها، و مخازن گیت‌هاب برای دیده‌شدن کار
   توسعه‌دهندگان ایرانی.
2. **هنر دیجیتال و مفهومی** — طراحی شخصیت، جهان‌سازی، و تمرکز بر شکل‌دادن به
   سبک‌های هنری تازه با ریشه در هنر ایرانی (نگارگری، نقاشی، تذهیب) به‌عنوان یک
   صدای بصری اصیل و مستقل — نه جایگزینی برای سبک‌های موجود.
3. **جامعه** — پروفایل اعضا، شبکه‌سازی، و مشارکت از طریق پول ریکوئست در
   پروژه‌های اعضای دیگر.

### اجرای محلی وب‌اپ

اپلیکیشن وب پروژه در مسیر `apps/web` قرار دارد و با Astro ساخته شده است. برای
اجرای آن به‌صورت محلی:

```bash
cd apps/web
npm install
npm run dev
```

## English

### About the Project

Parsi Games is a bilingual (Persian/English) platform connecting Iranian game
developers, digital artists, and open-source contributors around the world.
It is built for a future in which Iran freely reconnects with the
international community. Until then, this platform's purpose is to gather,
document, and produce open-source content and code from Iranian
professionals — both those scattered across the globe and the large, capable
community of professionals inside Iran — so that a ready body of people,
artwork, and code already exists.

### Three Pillars

1. **Technical / Engineering** — showcasing people, projects, and GitHub
   repositories to give Iranian developers' work visibility.
2. **Digital & Concept Art** — character design and world-building, with a
   focus on developing new artistic styles rooted in Iranian art (Persian
   miniature painting, naqqashi, illumination) as an original, independent
   visual voice — not a replacement for existing styles.
3. **Community** — member profiles, networking, and contributing to other
   members' projects via pull requests.

### Running the Web App Locally

The project's web app lives in `apps/web` and is built with Astro. To run it
locally:

```bash
cd apps/web
npm install
npm run dev
```
